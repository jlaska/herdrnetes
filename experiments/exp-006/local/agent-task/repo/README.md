# Kata

`kata.py` contains twelve stubs, `f01` to `f12`, each with a one-line docstring that specifies it. Implement them in order, one at a time, replacing only the `raise NotImplementedError` body of the function you are working on and using only the Python standard library. After each function, run `python3 check.py` (no arguments) to see which functions pass; it is a progress meter and always exits 0. Do not edit `check.py` or any other file.
